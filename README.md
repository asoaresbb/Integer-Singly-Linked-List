# ISLL Program (Integer Singly Linked List)

This project implements a **singly linked list in C++** with basic operations such as:

- Insertion
- Deletion
- Editing
- Printing
- And more...

---

## 🛠️ Compilation

Compile the program using `g++`:

```bash
g++ -g main-isll.cpp isll.cpp -o main-isll
```

## 🚀 Running the program

To run the program in the command line interface (CLI), use:

```bash
./main-isll
```

To redirect input from a text file and output to another text file, use:

```bash
./main-isll < input.txt > output.txt
```

## Example input.txt

```bash
insert_0 12
insert_pos 1 10
print
insert 20
print
delete 10
```
